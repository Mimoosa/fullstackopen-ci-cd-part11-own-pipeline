# Full Stack Open 2026 – Part 11 CI/CD Assignment
This repository contains my solution for the CI/CD assignment in Part 11 of the Full Stack Open course.

The project includes:
- A Node.js/Express backend
- A React frontend (Vite)
- Playwright end‑to‑end tests
- GitHub Actions CI pipeline
- Deployment to Render
